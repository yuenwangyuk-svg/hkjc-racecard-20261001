# 马匹登记表

2026年10月1日沙田第1–11场，电脑宽屏布局。

页面内容使用 PBKDF2-SHA256 / AES-256-GCM 加密；访问密码由页面拥有者另行提供，仓库不含明文页面、密码或本机服务密钥。此为静态页面内容锁，不提供服务器账户认证。

解锁后点击“刷新参赛表与赔率”，直接联网读取香港马会官方接口并同步六类候选组合的可用赔率与10元投注净利润。刷新保存于当前浏览器，不回写仓库。无可用赔率时不计算金额，接口失败时保留旧快照和时间。

历史往绩及模型分析是发布时的快照，刷新赔率不会重新训练模型；参赛条件改变会隐藏过时分析。圆环为未经校准的模型估算，金额是命中条件下的参考净利润，最终派彩以官方为准。
